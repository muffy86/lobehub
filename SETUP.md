# MCP Server/Tool Environment Setup Guide

This document describes the steps to install and configure all required dependencies, CLIs, and SDKs for enabling all MCP servers/tools in your environment, following best practices from the loaded skills.

---

## 1. Node.js Global Packages
Install required global packages:

```
npm install -g google-auth-library firebase-tools
```

## 2. Local Project Packages
Add missing dependencies to your project:

```
pnpm add google-auth-library firebase-tools
```

## 3. Dart SDK
- Download and install from: https://dart.dev/get-dart
- Add Dart to your system PATH.

## 4. Google Cloud SDK
- Download and install from: https://cloud.google.com/sdk/docs/install
- Add `gcloud` to your system PATH.

## 5. Other CLIs/SDKs
For each additional MCP server/tool (e.g., GKE, AlloyDB, Stripe, etc.):
- Download and install the required CLI/SDK from the official site
- Add to PATH as needed

## 6. PATH Update
Ensure all installed CLIs are available in your system PATH.

## 7. Tool/Server Limit
If you hit the tool/server cap, disable or remove unused ones.

## 8. Documentation
Keep this file updated as you add/remove tools or dependencies.

---

## After Setup
- Restart your terminal to apply PATH changes
- Verify installations by running each CLI with `--version` or `help`
- Commit and push this documentation and any related changes (e.g., package.json, .env, etc.)
